# Спринт 6 — завершение поиска и промежуточное ревью

Предыдущий этап: [спринт 5](sprint5.md). Ветка — от завершённой `feature/sprint-05`.

## 1. Состояния и асинхронная работа

- Проверить SearchViewModel и Initial / Searching / Success / Fail.
- Запускать поиск по лупе, использовать viewModelScope и Dispatchers.IO для данных.
- Показывать индикатор, список, пустую выдачу или ошибку.
- Ошибки источника не приводят к падению; отмена корутин не считается ошибкой поиска.
- Крестик очищает текст, скрывает результаты и отменяет запрос.
- Старый запрос не заменяет новый результат.
- UI-тексты — в strings.xml, UI работает через Domain и ViewModel.

Исходный текст предлагает Creator/фабрику. После миграции на Koin в спринте 5
не нужно возвращать ручную сборку: это альтернативные способы DI.
Фрагменты в этом сквозном проекте не используются.
