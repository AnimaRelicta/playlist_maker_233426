# Спринт 9 — сетевой поиск и экран плейлиста

## Поиск треков

- Подключить реальные запросы к iTunes Search API. Сохранить автоматический поиск после паузы ввода, историю и отмену устаревших запросов.
- Для найденного трека показать обложку из `artworkUrl100`, название из `trackName`, исполнителя из `artistName` и длительность из `trackTimeMillis` в формате `mm:ss`.
- Пока обложка загружается, отсутствует или недоступна, показывать заглушку. Обрабатывать отсутствующие поля и неожиданные ответы без падения и поломанной вёрстки.
- Различать загрузку, непустую выдачу, успешный ответ без результатов и ошибку запроса. При ошибке показывать заглушку и кнопку «Обновить», которая повторяет последний неудавшийся запрос.
- Кнопка «×» очищает запрос, скрывает клавиатуру, список и саму кнопку. Результаты отменённого запроса не должны возвращаться.

## Экран плейлиста

- Сверстать экран по [макету Figma](https://www.figma.com/design/p0tFHLFx0XBI7BijypwVjW/Playlist-Maker?node-id=1-1714&t=gPG8D49PKeI95d4R-1). Показать название, описание и список треков.
- Добавить `PlaylistsRepository.getPlaylist(id)` и `PlaylistViewModel`, которая получает ID через Koin и отдаёт поток выбранного плейлиста. Данные плейлистов пока берутся из mock-хранилища спринта 8.
- Связать список и детали через `PlaylistHost`. Передавать стабильный ID плейлиста. Нажатие на трек открывает его карточку. Системная кнопка «Назад» возвращает из деталей плейлиста в список, оттуда можно вернуться на главную.

## Критерии приёмки

- Реальный запрос возвращает треки с метаданными и обложками. Отдельно проверены пустая выдача, ошибка сети или сервера и повтор запроса.
- Длинный ввод, цифры, спецсимволы, лишние пробелы и пропуски полей в ответе не ломают поиск. Пропуски полей проверяются тестовыми ответами.
- Очистка поля скрывает клавиатуру и выдачу даже во время запроса.
- Плейлист открывается из списка с актуальными данными, трек открывается из плейлиста, возврат работает. Сценарии спринта 8 сохраняются, в том числе добавление найденного трека в плейлист.
