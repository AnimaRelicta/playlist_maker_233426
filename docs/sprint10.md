# Спринт 10. Локальное хранение

## Room

- Перевести репозитории плейлистов и избранного на Room. Сохранять созданные плейлисты, добавленные в них треки и избранные треки между запусками.
- Описать связь многие ко многим через PlaylistTrackEntity с полями trackId и playlistId. Добавить операции DAO для записи и удаления связи и чтения треков плейлиста. Для чтения использовать Room Relation с Junction или SQL JOIN.
- При открытии деталей трека получать состояние избранного из репозитория и показывать заполненное сердечко для сохранённого трека.

## DataStore

- Добавить SearchHistoryPreferences для записи и чтения истории запросов через Preferences DataStore. Перевести SearchHistoryRepositoryImpl на это хранилище и удалить DatabaseMock после перевода всех его потребителей.
- Пропускать пустые запросы. Хранить до 10 уникальных запросов, начиная с последнего. Повторный запрос перемещать в начало списка.

## Критерии приёмки

- После перезапуска доступны созданный плейлист, его треки и избранное. Один трек может входить в несколько плейлистов.
- После повторного открытия деталей добавленного в избранное трека сердечко заполнено.
- История поиска сохраняется после перезапуска. Пустой запрос не появляется, повтор не создаёт дубликат, одиннадцатый уникальный запрос вытесняет самый старый.
- Поиск, детали трека, плейлисты, избранное и настройки работают по прежним сценариям. Светлые экраны соответствуют макету.
