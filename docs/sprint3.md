# Спринт 3 — главный экран и переходы

## Задачи по порядку

1. Создать `MainActivity`, объявить её стартовой в манифесте.
2. Сверстать `MainScreen` на Jetpack Compose по светлому и тёмному макету Figma.
3. В первом учебном шаге обработать нажатия через Toast с названием кнопки.
4. В итоговой версии **заменить** Toast реальными переходами:
   создать `SearchActivity` и `SettingsActivity`, объявить в манифесте,
   открывать из соответствующих обработчиков.
5. На экранах-заглушках достаточно заголовков «Поиск» и «Настройки».
6. Проверить возврат на главный экран.

В актуальном макете также есть «Плейлисты» и «Избранное». Они открывают отдельные
заглушки, чтобы сохранить все четыре пункта макета. Их функционал здесь не реализуется.
Промежуточный Toast не должен оставаться в итоговой версии.

## Дизайн

- Рабочий размер 360×800 dp; синий `#3772E7`, основной текст / тёмный фон `#1A1B22`.
- Шапка 70 dp, верхние углы меню 16 dp, отступ перед строками 8 dp, строки 66 dp.
- Используется системный шрифт.
  Побитовое совпадение растеризации текста с Figma не требуется.
