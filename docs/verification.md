# Проверки по спринтам

## Спринт 3 — главный экран и навигация

### Ручная проверка

1. Откройте Playlist Maker в светлой теме. Проверьте синюю шапку и порядок четырёх пунктов меню по макету.
2. Откройте «Поиск», «Плейлисты», «Избранное» и «Настройки». На каждом экране проверьте заголовок и возврат на главную кнопкой «Назад».
3. Включите системную тёмную тему. Проверьте тёмную панель меню, светлые надписи и иконки.

### Автоматические проверки

| Проверка | Команда |
|---|---|
| Сборка APK, локальные тесты и Android Lint | `./gradlew.bat assembleDebug testDebugUnitTest lintDebug` |
| Структура ресурсов и объявлений Activity | `uv run android-project check` |
| Сравнение двух тем с локальными эталонами Figma после тестов | `uv run python tools/compare_figma.py` |

Для сравнения нужны [локальные эталоны](../figma/README.md). Области текста исключены из сравнения, поскольку приложение использует системный шрифт.

### Результат

- APK собран, все 8 локальных тестов и Android Lint прошли.
- Проверка структуры и сравнение обеих тем с Figma прошли.
- Интерфейс и переходы проверены на телефоне.
