# Ветки и коммиты

`main` содержит принятые спринты. Рабочие ветки сохраняются накопительно:
`feature/sprint-03` → `feature/sprint-04` → `feature/sprint-05` → `feature/sprint-06`.

После автоматических проверок и ручной проверки на телефоне этап фиксируется отдельным коммитом. В сообщении коммита отмечаются выполненные проверки:

```text
- [x] APK собран
- [x] Тесты и Android Lint прошли
- [x] Интерфейс и переходы проверены на телефоне
```

Принятый этап сливается в `main`.
