# Макеты Playlist Maker

[Исходный макет Figma](https://www.figma.com/design/p0tFHLFx0XBI7BijypwVjW/Playlist-Maker?node-id=0-1).

Экспорт и скриншоты хранятся на Google Drive. Ресурсы приложения находятся в `app/src/main/res`.

Для локального сравнения разместите в `figma/reference` файлы `main-light@2x.png` (720×1600) и `main-dark.png` (360×800). После тестов запустите `uv run python tools/compare_figma.py`.

Для спринта 4 разместите там же экспорты `search-default.png` и `main-and-settings.png`.
Запустите `uv run python tools/compare_figma.py --sprint 4` после тестов.
